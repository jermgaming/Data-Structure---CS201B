# 1.3.12. Implementation of sparse matrix using arrays
## 📋 Overview
This C program implements a sparse matrix using a 2D array and generates its array representation. A sparse matrix is a matrix that contains a large number of zero elements, and its array representation is a compact way of storing only the non-zero elements.

## 🎯 Purpose
The purpose of this program is to demonstrate how to implement a sparse matrix using a 2D array and generate its array representation. This program solves the problem of efficiently storing and representing sparse matrices, which is important in various fields such as linear algebra, computer graphics, and data analysis.

## ✨ Key Features
* Implementation of a sparse matrix using a 2D array
* Generation of the array representation of the sparse matrix
* User input for the row and column sizes of the sparse matrix
* User input for the values of each element in the sparse matrix
* Printing of the array representation of the sparse matrix

## 🏗️ Data Structures Used
The program uses the following data structures:
* **2D Array (sparse_matrix)**: A 10x10 2D array is used to store the sparse matrix. The array is initialized with a fixed size of 10x10, but the program allows the user to input the actual number of rows and columns.
* **Arrays (implicitly used in loops)**: The program uses arrays implicitly in the loops to store the row and column indices and the corresponding non-zero values of the sparse matrix.

## 🔧 Implementation Details

### Algorithm Explanation
The program uses the following algorithm:
1. The program prompts the user to input the row and column sizes of the sparse matrix.
2. The program uses nested loops to iterate over the rows and columns of the sparse matrix.
3. For each element, the program prompts the user to input its value.
4. The program stores the input values in the 2D array (sparse_matrix).
5. The program then uses another set of nested loops to iterate over the rows and columns of the sparse matrix.
6. For each element, the program checks if its value is non-zero.
7. If the element is non-zero, the program prints its array representation, which includes the row index, column index, and value.
