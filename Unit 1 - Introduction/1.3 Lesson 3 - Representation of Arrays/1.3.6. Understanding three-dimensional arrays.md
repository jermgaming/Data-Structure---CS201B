# 1.3.6. Understanding three-dimensional arrays
## 📋 Overview
This C program demonstrates the usage of three-dimensional arrays by prompting the user to input the dimensions of a 3D array and then asking for the values to fill the array. After that, it prints out the values of the array.

## 🎯 Purpose
The purpose of this program is to provide a simple example of how three-dimensional arrays can be used in C programming. It allows users to create a 3D array with custom dimensions, fill it with values, and then print out the contents of the array. This can be useful for understanding the concept of multi-dimensional arrays and how they can be applied in real-world programming scenarios.

## ✨ Key Features
* Allows users to specify the dimensions of a 3D array
* Prompts users to input values for each element in the 3D array
* Prints out the values of the 3D array
* Demonstrates the use of nested loops to iterate over a 3D array

## 🏗️ Data Structures Used
The primary data structure used in this program is a three-dimensional array (`int a[3][3][3]`). However, the array dimensions are not fixed and are determined by the user's input. A three-dimensional array is a data structure that consists of a collection of two-dimensional arrays, where each two-dimensional array represents a page or a layer in the 3D array. Each element in the 3D array is identified by three indices: page, row, and column.
