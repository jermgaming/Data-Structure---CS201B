# 1.3.2. Write a C program to read and print One Dimensional Array of integers

## 📋 Overview
This C program reads a specified number of integers from the user into a one-dimensional array and prints all the elements to the console. It demonstrates fundamental array input and output operations in C.

## 🎯 Purpose
The purpose of this program is to practice reading and displaying elements of a one-dimensional integer array. It reinforces the concepts of array declaration, loop-based input, and sequential output, which are essential skills for working with arrays in C.

## ✨ Key Features
* Reads the number of elements from the user
* Accepts integer values into a one-dimensional array using a loop
* Prints all array elements to the console

## 🏗️ Data Structures Used
The program uses a one-dimensional integer array to store the elements entered by the user. The array size is determined at runtime based on the user's input.

## 🔧 Implementation Details

### Algorithm Explanation
1. Prompt the user to enter the number of elements `n`.
2. Declare an integer array of size `n`.
3. Loop from `0` to `n-1`, reading each element from standard input.
4. Loop from `0` to `n-1`, printing each element to the console.

### Functions Documentation
- **`main()`**
  - **Purpose**: Entry point; handles all input/output operations.
  - **Parameters**: None.
  - **Returns**: `void`.
  - **Logic**: Reads `n`, populates the array via `scanf`, and displays elements via `printf`.

## 💻 Compilation & Usage

### Compilation
```bash
gcc "1.3.2. Write a C program to read and print One Dimensional Array of integers.c" -o read_print_array
```

### Running the Program
```bash
./read_print_array
```

## 📥 Input/Output

### Input
* An integer `n` — the number of elements to read.
* `n` integer values for the array.

### Output
* The elements of the array printed to the console.

## 📊 Complexity Analysis
- **Time Complexity**: O(n) — the array is traversed twice (once for input, once for output).
- **Space Complexity**: O(n) — storage proportional to the number of elements.

## 🧪 Example Run
```
Enter how many values you want to read : 4
Enter the value of a[0] : 10
Enter the value of a[1] : 20
Enter the value of a[2] : 30
Enter the value of a[3] : 40
The array elements are :  10  20  30  40
```

## ⚠️ Edge Cases & Error Handling
* The program does not validate that `n` is positive; entering zero or a negative value may cause unexpected behavior.
* No bounds checking is performed beyond the declared array size.

## 🚧 Limitations
* The array size is fixed at compile time (size 10 in the sample), which limits the number of elements that can be stored.
* No error handling for invalid input types (e.g., characters instead of integers).

## 📝 Notes
This program is for educational purposes. It can be extended to support dynamic memory allocation for larger or variable-sized arrays.
