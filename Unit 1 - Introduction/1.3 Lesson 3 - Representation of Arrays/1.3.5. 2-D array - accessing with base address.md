# 1.3.5. 2-D array - accessing with base address
## 📋 Overview
This C program demonstrates how to access and manipulate a 2D array using its base address. It prompts the user to input the row and column sizes of a matrix, then asks for the values of each element in the matrix. Finally, it displays the entered matrix.

## 🎯 Purpose
The main purpose of this program is to illustrate the concept of accessing and manipulating 2D arrays using pointer arithmetic. It provides a simple and intuitive example of how to work with 2D arrays in C, which is an essential skill for any C programmer. By understanding how to access and manipulate 2D arrays, developers can create more complex and efficient data structures, such as matrices, graphs, and tables.

## ✨ Key Features
* Accesses and manipulates a 2D array using its base address
* Prompts the user to input the row and column sizes of a matrix
* Asks for the values of each element in the matrix
* Displays the entered matrix
* Uses pointer arithmetic to access and manipulate the elements of the 2D array
* Uses nested loops to iterate over the rows and columns of the matrix

## 🏗️ Data Structures Used
The program uses a 2D array (`int num[5][5]`) to store the matrix. A 2D array is a collection of rows, where each row is an array of integers. The program also uses pointers to access and manipulate the elements of the 2D array. In C, a 2D array is stored in row-major order, which means that the elements of each row are stored contiguously in memory. This allows the program to use pointer arithmetic to access and manipulate the elements of the 2D array.
