# 1.6.9. Quick Sort
## 📋 Overview
This C program implements the Quick Sort algorithm to sort an array of integers in ascending order. The program takes an array of integers as input, sorts it using the Quick Sort algorithm, and then prints the sorted array.

## 🎯 Purpose
The purpose of this program is to demonstrate the implementation of the Quick Sort algorithm, a divide-and-conquer algorithm that is widely used for sorting large datasets. The Quick Sort algorithm works by selecting a pivot element, partitioning the array around the pivot, and recursively sorting the subarrays. This program solves the problem of sorting an array of integers in ascending order, which is a common task in many applications, such as data analysis, file systems, and database management.

## ✨ Key Features
* Implements the Quick Sort algorithm for sorting an array of integers
* Takes an array of integers as input and prints the sorted array
* Uses recursive function calls to sort the subarrays
* Handles arrays of varying sizes
* Prints the original and sorted arrays for comparison

## 🔧 Implementation Details

### Algorithm Explanation
The Quick Sort algorithm works as follows:
1. Select a pivot element from the array.
2. Partition the array around the pivot element, such that all elements less than the pivot are on the left of the pivot, and all elements greater than the pivot are on the right of the pivot.
3. Recursively apply the Quick Sort algorithm to the subarrays on either side of the pivot element.
4. Combine the sorted subarrays to produce the final sorted array.

## 📊 Complexity Analysis
- **Time Complexity**: The time complexity of the Quick Sort algorithm is:
  - **Best case**: O(n log n), which occurs when the pivot element is chosen such that it divides the array into two halves of roughly equal size.
  - **Average case**: O(n log n), which occurs when the pivot element is chosen randomly.
  - **Worst case**: O(n^2), which occurs when the pivot element is chosen such that it is the smallest or largest element in the array.
- **Space Complexity**: The space complexity of the Quick Sort algorithm is O(log n), which is the maximum depth of the recursive call stack.
