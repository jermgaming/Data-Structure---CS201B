# 1.6.3. Submatrix Sum Calculation

## 📋 Overview
This C program reads an `n x m` integer matrix from the user and computes the sum of all elements within a specified submatrix defined by two corner coordinates `(x1, y1)` and `(x2, y2)`. It demonstrates 2D array manipulation and subarray sum calculations.

## 🎯 Purpose
The purpose of this program is to solve the submatrix sum problem — a classic problem in competitive programming and data structure courses. It helps understand 2D array traversal and the use of row and column indices to define a region within a matrix.

## ✨ Key Features
* Reads an `n x m` matrix of integers from the user
* Accepts a submatrix defined by top-left `(x1, y1)` and bottom-right `(x2, y2)` coordinates (1-indexed)
* Calculates and prints the sum of all elements within the specified submatrix

## 🏗️ Data Structures Used
* **2D Array**: A variable-length 2D integer array `arr[n][m]` stores the matrix elements.

## 🔧 Implementation Details

### Algorithm Explanation
1. Read dimensions `n` (rows) and `m` (columns).
2. Populate the 2D array with `n * m` integer values.
3. Read submatrix boundaries: `x1, y1` (top-left, 1-indexed) and `x2, y2` (bottom-right, 1-indexed).
4. Iterate rows from `x1-1` to `x2-1` and columns from `y1-1` to `y2-1`, accumulating the sum.
5. Print the sum.

### Functions Documentation
- **`main()`**
  - **Purpose**: Entry point; handles all matrix input, submatrix selection, and sum output.
  - **Parameters**: None.
  - **Returns**: `int` (0 on success).
  - **Logic**: Reads the matrix, reads the submatrix coordinates, traverses the submatrix region, computes and prints the sum.

## 💻 Compilation & Usage

### Compilation
```bash
gcc "1.6.3. Submatrix Sum Calculation.c" -o submatrix_sum
```

### Running the Program
```bash
./submatrix_sum
```

## 📥 Input/Output

### Input
* Two integers `n` and `m` — dimensions of the matrix.
* `n * m` integers — the matrix elements.
* Four integers `x1 y1 x2 y2` — the submatrix boundaries (1-indexed).

### Output
* A single integer — the sum of elements in the submatrix.

## 📊 Complexity Analysis
- **Time Complexity**: O(n × m) to read the matrix; O((x2-x1+1) × (y2-y1+1)) to compute the submatrix sum.
- **Space Complexity**: O(n × m) to store the matrix.

## 🧪 Example Run
```
3 3
1 2 3
4 5 6
7 8 9
1 1 2 2
12
```
*(Sum of elements in rows 1–2, columns 1–2: 1+2+4+5 = 12)*

## ⚠️ Edge Cases & Error Handling
* No validation of the submatrix bounds; if `x1 > x2` or `y1 > y2`, or if coordinates exceed matrix dimensions, undefined behavior may occur.
* Does not handle negative dimensions.

## 🚧 Limitations
* Uses variable-length arrays (VLAs), which are supported in C99 but not guaranteed in all C standards.
* No dynamic memory allocation; limited by stack size for very large matrices.

## 📝 Notes
This program is intended for educational purposes. A production-quality solution would use prefix sums for O(1) submatrix queries after O(n×m) preprocessing.
