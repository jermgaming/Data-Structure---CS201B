# 1.6.2. Duplicate Elements in an Array
## 📋 Overview
This C program determines whether an array of integers contains any duplicate elements. It reads an array of integers from the user, checks for duplicates, and outputs a boolean value indicating whether any duplicates were found.

## 🎯 Purpose
The purpose of this program is to solve the problem of detecting duplicate elements in an array. This is a common task in many areas of computer science, such as data processing, data analysis, and algorithm design. By providing a simple and efficient solution to this problem, this program can be useful in a variety of applications.

## ✨ Key Features
* Reads an array of integers from the user

* Outputs a boolean value indicating whether any duplicates were found
* Uses a nested loop algorithm to check for duplicates
* Dynamically allocates memory for the array using `malloc()`

## 🔧 Implementation Details

### Algorithm Explanation
The program uses a simple nested loop algorithm to check for duplicates:
1. The outer loop iterates over each element in the array (`i` ranges from 0 to `n-1`).
2. The inner loop iterates over the remaining elements in the array (`j` ranges from `i+1` to `n-1`).
3. If a match is found between the current element (`arr[i]`) and any of the remaining elements (`arr[j]`), the `dup` flag is set to 1 and the inner loop is terminated.
4. If the `dup` flag is still 0 after the outer loop completes, it means that no duplicates were found.
