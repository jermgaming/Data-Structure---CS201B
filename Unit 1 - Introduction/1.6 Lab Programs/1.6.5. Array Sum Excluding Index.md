# 1.6.5. Array Sum Excluding Index

## 📋 Overview
This C program, for each element in an array, computes the sum of all other elements (i.e., the total sum minus the element at the current index). It processes multiple test cases and prints a space-separated output line for each test case.

## 🎯 Purpose
The purpose of this program is to demonstrate an efficient technique for computing an "array sum excluding the current element" without using a nested loop. By precomputing the total sum, each result is obtained in O(1) per element, leading to an overall O(n) solution per test case.

## ✨ Key Features
* Handles multiple test cases
* Reads a dynamic-size array for each test case
* Computes and prints the sum of all elements excluding the current index for each position
* Uses dynamic memory allocation with `malloc`

## 🏗️ Data Structures Used
* **Dynamically allocated array**: `int *arr` allocated with `malloc(n * sizeof(int))` to hold the input elements.

## 🔧 Implementation Details

### Algorithm Explanation
1. Read the number of test cases `t`.
2. For each test case, call `solve()`:
   a. Read `n` and allocate `arr` of size `n`.
   b. Read each element, accumulating a running `sum`.
   c. For each index `i`, print `sum - arr[i]`.

### Functions Documentation
- **`solve()`**
  - **Purpose**: Processes a single test case — reads the array, computes prefix sums, and prints results.
  - **Parameters**: None.
  - **Returns**: `void`.
  - **Logic**: Reads `n`, allocates array, computes total sum during input, then outputs `sum - arr[i]` for each `i`.

- **`main()`**
  - **Purpose**: Entry point; reads the number of test cases and calls `solve()` for each.
  - **Parameters**: None.
  - **Returns**: `int` (0 on success).

## 💻 Compilation & Usage

### Compilation
```bash
gcc "1.6.5. Array Sum Excluding Index.c" -o sum_excluding_index
```

### Running the Program
```bash
./sum_excluding_index
```

## 📥 Input/Output

### Input
* An integer `t` — the number of test cases.
* For each test case:
  * An integer `n` — the size of the array.
  * `n` integers — the array elements.

### Output
* For each test case, a space-separated line where the `i`-th value is the sum of all elements except `arr[i]`.

## 📊 Complexity Analysis
- **Time Complexity**: O(n) per test case — single pass to compute sum, single pass to print results.
- **Space Complexity**: O(n) per test case for the dynamically allocated array.

## 🧪 Example Run
```
1
5
1 2 3 4 5
14 13 12 11 10
```
*(For n=5 with elements [1,2,3,4,5], total sum=15; output is [14,13,12,11,10])*

## ⚠️ Edge Cases & Error Handling
* No check for `malloc` failure; if allocation fails, the program may crash.
* The dynamically allocated array is never freed, which results in a memory leak.
* No validation that `n > 0`.

## 🚧 Limitations
* Memory is not freed after use (`free(arr)` is missing).
* Does not handle integer overflow for very large sums.

## 📝 Notes
This program is for educational purposes. A production implementation should include proper memory management and overflow protection.
