# 1.6.4. Fear Calculation in Array

## 📋 Overview
This C program calculates a "fear value" for each element in an array. For each element, the fear value is defined as the distance to the nearest subsequent element that is strictly smaller than it. If no such element exists to the right, the fear value defaults to 1.

## 🎯 Purpose
The purpose of this program is to practise array traversal and nearest-smaller-element logic. It simulates a scenario where the "fear" of each value in the array is measured by how far away the next smaller value is, reinforcing skills in nested loop design and conditional logic.

## ✨ Key Features
* Reads an array of `n` integers
* Computes the fear value for each element based on the distance to the next smaller element
* Outputs the product of all fear values

## 🏗️ Data Structures Used
* **Array**: A variable-length integer array `arr[n]` stores the input values, and `fear[n]` stores the computed fear values.

## 🔧 Implementation Details

### Algorithm Explanation
1. Read the number of elements `n` and populate the array `arr`.
2. Set `fear[n-1] = 1` (last element has no element to its right).
3. For each element `i` from `0` to `n-2`, iterate `j` from `i+1` to `n-1`. If `arr[i] > arr[j]`, set `fear[i] = j+1-i` and break. Otherwise, set `fear[i] = 1`.
4. Compute the product of all fear values and print it.

### Functions Documentation
- **`main()`**
  - **Purpose**: Entry point; computes and prints the product of fear values.
  - **Parameters**: None.
  - **Returns**: `int` (0 on success).
  - **Logic**: Reads input, computes fear array via nested loops, multiplies all fear values, and prints the result.

```

```

## 📥 Input/Output

### Input
* An integer `n` — the number of elements.
* `n` integers — the array values.

### Output
* A single integer — the product of all fear values.

## 📊 Complexity Analysis
- **Time Complexity**: O(n²) — nested loops to find the nearest smaller element for each position.
- **Space Complexity**: O(n) — for the `arr` and `fear` arrays.

## 🧪 Example Run
```
5
4 2 3 1 5
Input array: 4 2 3 1 5
Fear values: 1 1 1 1 1
Product: 1
```

## ⚠️ Edge Cases & Error Handling
* The variable `ANS` is not initialized before being used in the multiplication loop, which may produce incorrect results (undefined behavior in C).
* If `n = 1`, the loop body for fear computation is skipped and only `fear[0] = 1` is set.

## 🚧 Limitations
* The uninitialized `ANS` variable is a bug in the current implementation; it should be initialized to `1` before the product loop.
* O(n²) complexity; a stack-based approach can solve it in O(n).

## 📝 Notes
This program is intended for educational purposes. A more efficient implementation would use a monotonic stack to find the nearest smaller element in O(n) time.
