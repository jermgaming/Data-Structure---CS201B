## 📋 Overview
The Merge Sort program is a C implementation of the Merge Sort algorithm, designed to sort an array of integers in ascending order. This program takes an array of integers as input, sorts it using the Merge Sort algorithm, and then prints the sorted array.

## 🎯 Purpose
The purpose of this program is to demonstrate the implementation of the Merge Sort algorithm, which is a divide-and-conquer algorithm that works by dividing the array into two halves, sorting each half, and then merging the two sorted halves into a single sorted array. This program solves the problem of sorting an array of integers in an efficient and stable manner.

## 🔧 Implementation Details
### Algorithm Explanation
The Merge Sort algorithm works as follows:
1. Divide the array into two halves until each subarray contains only one element.
2. Merge adjacent subarrays to produce a sorted subarray.
3. Repeat the merge process until the entire array is sorted.
The algorithm uses a recursive approach to divide the array into smaller subarrays and then merges the subarrays using a iterative approach.
