# 1.7.8. Sort the books according to their price by divide and conquer techniques

## 📋 Overview
This C program reads the prices of a set of books (as floating-point values) and sorts them in ascending order. It prints the sorted prices, each on a new line, formatted to two decimal places. The program is presented in the context of divide-and-conquer techniques for sorting.

## 🎯 Purpose
The purpose of this program is to practise sorting floating-point data in a real-world scenario using divide-and-conquer framing. Although the current implementation uses Bubble Sort, the program structure is designed to be extended with divide-and-conquer algorithms such as Merge Sort.

## ✨ Key Features
* Validates that the number of books is positive
* Reads book prices as floating-point numbers with per-book prompts
* Sorts prices in ascending order
* Displays the sorted prices formatted to two decimal places

## 🏗️ Data Structures Used
* **Dynamically allocated float array**: `float *arr` allocated with `malloc(n * sizeof(float))` to store prices.

## 🔧 Implementation Details

### Algorithm Explanation
1. Prompt and read `n`; validate it is positive.
2. Allocate a float array of size `n` and read each price.
3. Call `bubbleSort()` to sort prices in ascending order via adjacent-element swaps.
4. Print the sorted prices with `printArr()`.

### Functions Documentation
- **`bubbleSort(float arr[], int n)`**
  - **Purpose**: Sorts the float array in ascending order using Bubble Sort.
  - **Parameters**: `arr` — price array; `n` — number of books.
  - **Returns**: `void`.
  - **Logic**: Nested loops; swaps `arr[j]` and `arr[j+1]` when `arr[j] > arr[j+1]`.

- **`printArr(float arr[], int n)`**
  - **Purpose**: Prints each price on a new line with 2 decimal places.
  - **Parameters**: `arr` — float array; `n` — number of elements.
  - **Returns**: `void`.

- **`main()`**
  - **Purpose**: Entry point; drives input, sorting, and output.
  - **Parameters**: None.
  - **Returns**: `int` (0 on success).

## 💻 Compilation & Usage

### Compilation
```bash
gcc "1.7.8. Sort the books according to their price by divide and conquer techniques.c" -o sort_books_dc
```

### Running the Program
```bash
./sort_books_dc
```

## 📥 Input/Output

### Input
* An integer `n` — the number of books.
* `n` floating-point values — prices entered individually with a prompt per book.

### Output
* A sorted list of book prices, each on a new line formatted to two decimal places.

## 📊 Complexity Analysis
- **Time Complexity**: O(n²) — Bubble Sort.
- **Space Complexity**: O(n) — dynamically allocated array.

## 🧪 Example Run
```
Number of books: 3
Book 1 price: 19.99
Book 2 price: 5.49
Book 3 price: 11.25
Sorted list of book prices:
5.49
11.25
19.99
```

## ⚠️ Edge Cases & Error Handling
* Prints `"Invalid number of books"` and returns `0` if `n ≤ 0`.
* No check for `malloc` failure.

## 🚧 Limitations
* Memory is never freed (memory leak).
* Current implementation uses Bubble Sort rather than a true divide-and-conquer algorithm.

## 📝 Notes
This program is for educational purposes. To implement a true divide-and-conquer solution, replace `bubbleSort` with a Merge Sort implementation that divides the array into halves, recursively sorts each half, and merges them.
