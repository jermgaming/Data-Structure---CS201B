# 1.7.6. Sort the books based on popularity

## 📋 Overview
This C program reads the popularity scores of a set of books and sorts them in descending order using Bubble Sort. It prints the original popularity scores before sorting and the sorted scores after sorting, simulating a book ranking by popularity.

## 🎯 Purpose
The purpose of this program is to apply the Bubble Sort algorithm to a practical scenario — sorting books by their popularity scores in descending order. It reinforces the concepts of sorting, array manipulation, and formatted output.

## ✨ Key Features
* Validates that the number of books is positive
* Reads and displays original popularity scores
* Sorts scores in descending order using Bubble Sort
* Displays the sorted popularity scores

## 🏗️ Data Structures Used
* **Dynamically allocated array**: `int *arr` allocated with `malloc(n * sizeof(int))` to store popularity scores.

## 🔧 Implementation Details

### Algorithm Explanation
1. Read `n` and validate it is positive.
2. Allocate an integer array of size `n` and read the popularity scores.
3. Print the original scores via `printArr()`.
4. Call `bubbleSort()` to sort in descending order.
5. Print the sorted scores via `printArr()`.

### Functions Documentation
- **`bubbleSort(int arr[], int n)`**
  - **Purpose**: Sorts the array in descending order using Bubble Sort.
  - **Parameters**: `arr` — array of popularity scores; `n` — number of elements.
  - **Returns**: `void`.
  - **Logic**: Swaps adjacent elements when `arr[j] < arr[j+1]`, moving higher values toward the front.

- **`printArr(int arr[], int n)`**
  - **Purpose**: Prints all array elements separated by spaces followed by a newline.
  - **Parameters**: `arr` — the array; `n` — number of elements.
  - **Returns**: `void`.

- **`main()`**
  - **Purpose**: Entry point; reads input and drives sorting and output.
  - **Parameters**: None.
  - **Returns**: `int` (0 on success).

## 💻 Compilation & Usage

### Compilation
```bash
gcc "1.7.6. Sort the books based on popularity.c" -o sort_books_popularity
```

### Running the Program
```bash
./sort_books_popularity
```

## 📥 Input/Output

### Input
* An integer `n` — the number of books.
* `n` integers — the popularity score of each book.

### Output
* The original popularity scores on one line.
* The sorted (descending) popularity scores on another line.

## 📊 Complexity Analysis
- **Time Complexity**: O(n²) — Bubble Sort.
- **Space Complexity**: O(n) — for the dynamically allocated array.

## 🧪 Example Run
```
4
50 80 30 70
Original Popularity Scores: 50 80 30 70
Sorted Popularity Scores: 80 70 50 30
```

## ⚠️ Edge Cases & Error Handling
* Prints `"Invalid number"` and returns `0` if `n ≤ 0`.
* No check for `malloc` failure.

## 🚧 Limitations
* Memory is never freed after use (memory leak).
* O(n²) time complexity is inefficient for large datasets.

## 📝 Notes
This program is for educational purposes. A real-world book ranking system would use more efficient sorting and may also sort by multiple criteria (e.g., title as a tiebreaker).
