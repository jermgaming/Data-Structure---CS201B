# 1.7.5. Sort the scores of athletes in descending order

## 📋 Overview
This C program reads the scores of a set of athletes and sorts them in descending order using Bubble Sort. It prints the original scores before sorting and the sorted scores after sorting.

## 🎯 Purpose
The purpose of this program is to demonstrate sorting a real-world dataset (athlete scores) in descending order. It applies the Bubble Sort algorithm with a modified comparison condition to arrange elements from highest to lowest, which is a common requirement in rankings and leaderboards.

## ✨ Key Features
* Validates that the number of athletes is positive
* Reads and displays the original score array
* Sorts scores in descending order using Bubble Sort
* Displays the sorted scores

## 🏗️ Data Structures Used
* **Dynamically allocated array**: `int *arr` allocated with `malloc(n * sizeof(int))` to store scores.

## 🔧 Implementation Details

### Algorithm Explanation
1. Read `n` and validate it is positive.
2. Allocate an integer array of size `n` and read the scores.
3. Print the original scores via `printArr()`.
4. Call `bubbleSort()` which sorts in descending order by swapping `arr[j]` and `arr[j+1]` when `arr[j] < arr[j+1]`.
5. Print the sorted scores via `printArr()`.

### Functions Documentation
- **`bubbleSort(int arr[], int n)`**
  - **Purpose**: Sorts the array in descending order using Bubble Sort.
  - **Parameters**: `arr` — array of scores; `n` — number of scores.
  - **Returns**: `void`.
  - **Logic**: Swaps adjacent elements when the left element is smaller than the right, bubbling the largest values to the front.

- **`printArr(int arr[], int n)`**
  - **Purpose**: Prints all elements of the array separated by spaces.
  - **Parameters**: `arr` — the array; `n` — number of elements.
  - **Returns**: `void`.

- **`main()`**
  - **Purpose**: Entry point; reads input, prints original and sorted arrays.
  - **Parameters**: None.
  - **Returns**: `int` (0 on success).

## 💻 Compilation & Usage

### Compilation
```bash
gcc "1.7.5. Sort the scores of athletes in descending order.c" -o sort_scores
```

### Running the Program
```bash
./sort_scores
```

## 📥 Input/Output

### Input
* An integer `n` — the number of athletes.
* `n` integers — the scores of each athlete.

### Output
* The original scores on one line.
* The sorted (descending) scores on another line.

## 📊 Complexity Analysis
- **Time Complexity**: O(n²) — Bubble Sort with two nested loops.
- **Space Complexity**: O(n) — for the dynamically allocated array.

## 🧪 Example Run
```
5
85 90 70 95 80
Original Scores: 85 90 70 95 80
Sorted Scores: 95 90 85 80 70
```

## ⚠️ Edge Cases & Error Handling
* Prints `"Invalid number"` and returns `0` if `n ≤ 0`.
* No check for `malloc` failure.

## 🚧 Limitations
* The allocated array is never freed (memory leak).
* Bubble Sort is O(n²) and inefficient for large inputs.

## 📝 Notes
This program is for educational purposes. A production implementation should free allocated memory and use a more efficient sorting algorithm for large datasets.
