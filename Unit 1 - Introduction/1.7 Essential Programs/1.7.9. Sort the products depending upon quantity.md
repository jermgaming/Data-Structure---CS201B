# 1.7.9. Sort the products depending upon quantity
## 📋 Overview
This C program sorts an array of integers representing product quantities in ascending order using the bubble sort algorithm. It takes the number of products and their respective quantities as input, sorts the quantities, and then prints the original and sorted quantities.

## 🎯 Purpose
The main purpose of this program is to provide a simple solution for sorting product quantities in ascending order. This can be useful in various inventory management and analysis tasks, such as identifying products with the lowest quantities or analyzing the distribution of product quantities to identify trends or patterns.

## ✨ Key Features

* Takes the number of products and their respective quantities as input
* Prints the original and sorted product quantities
* Handles invalid input (number of products less than or equal to 0)
* Uses dynamically allocated memory for the array of product quantities

## 🔧 Implementation Details

### Algorithm Explanation
The bubble sort algorithm is used to sort the array of product quantities. Here's a step-by-step breakdown of the algorithm:
1. The outer loop iterates `n` times, where `n` is the size of the array.
2. The inner loop iterates from the first element to the `n-i-1` element.
3. In each iteration of the inner loop, the program checks if the current element is greater than the next element.
4. If the current element is greater than the next element, the program swaps them.
5. This process continues until the array is sorted.
