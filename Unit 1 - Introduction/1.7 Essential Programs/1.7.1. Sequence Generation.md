# 1.7.1. Sequence Generation
## 📋 Overview
This C program generates a new sequence of numbers based on the input sequence. The new sequence is generated by adding each element in the input sequence with its next element, starting from the second last element and moving backwards to the first element. The last element of the input sequence is copied as is to the new sequence.

## 🎯 Purpose
The purpose of this program is to demonstrate a simple sequence generation algorithm. It takes an input sequence of integers, applies a transformation to generate a new sequence, and then outputs the resulting sequence.
