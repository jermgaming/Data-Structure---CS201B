# 1.7.7. Sort the books according to their price

## 📋 Overview
This C program reads the prices of a set of books (as floating-point values) and sorts them in ascending order using Bubble Sort. It then prints the sorted prices, each on a new line, formatted to two decimal places.

## 🎯 Purpose
The purpose of this program is to demonstrate sorting of floating-point data in a real-world context — ordering books by price. It reinforces the use of `float` arrays, Bubble Sort with floating-point comparisons, and formatted output using `printf`.

## ✨ Key Features
* Validates that the number of books is positive
* Reads book prices as floating-point numbers
* Sorts prices in ascending order using Bubble Sort
* Prints each sorted price formatted to two decimal places

## 🏗️ Data Structures Used
* **Dynamically allocated float array**: `float *arr` allocated with `malloc(n * sizeof(float))` to store book prices.

## 🔧 Implementation Details

### Algorithm Explanation
1. Prompt and read `n` (number of books); validate it is positive.
2. Allocate a float array of size `n`.
3. Read each book price with a prompt.
4. Call `bubbleSort()` to sort prices in ascending order.
5. Print the sorted list with `printArr()`.

### Functions Documentation
- **`bubbleSort(float arr[], int n)`**
  - **Purpose**: Sorts the float array in ascending order.
  - **Parameters**: `arr` — array of prices; `n` — number of elements.
  - **Returns**: `void`.
  - **Logic**: Swaps adjacent elements when `arr[j] > arr[j+1]`.

- **`printArr(float arr[], int n)`**
  - **Purpose**: Prints each element on a new line formatted to 2 decimal places.
  - **Parameters**: `arr` — float array; `n` — number of elements.
  - **Returns**: `void`.

- **`main()`**
  - **Purpose**: Entry point; handles input, sorting, and output.
  - **Parameters**: None.
  - **Returns**: `int` (0 on success).

## 💻 Compilation & Usage

### Compilation
```bash
gcc "1.7.7. Sort the books according to their price.c" -o sort_books_price
```

### Running the Program
```bash
./sort_books_price
```

## 📥 Input/Output

### Input
* An integer `n` — the number of books.
* `n` floating-point numbers — the price of each book (entered with prompts).

### Output
* A sorted list of book prices, each on a new line, formatted to two decimal places.

## 📊 Complexity Analysis
- **Time Complexity**: O(n²) — Bubble Sort.
- **Space Complexity**: O(n) — for the dynamically allocated array.

## 🧪 Example Run
```
Number of books: 3
Book 1 price: 15.99
Book 2 price: 7.49
Book 3 price: 12.00
Sorted list of book prices:
7.49
12.00
15.99
```

## ⚠️ Edge Cases & Error Handling
* Prints `"Invalid number of books"` and returns `0` if `n ≤ 0`.
* No check for `malloc` failure.

## 🚧 Limitations
* Memory is never freed after use (memory leak).
* Floating-point comparison may introduce minor precision issues.

## 📝 Notes
This program is for educational purposes. For large datasets, a more efficient algorithm such as Merge Sort is recommended.
