# 1.7.3. Sort the Array using Selection Sort

## 📋 Overview
This C program reads an array of integers from the user and sorts it in ascending order using the Selection Sort algorithm. It then prints the sorted array to the console.

## 🎯 Purpose
The purpose of this program is to implement and understand the Selection Sort algorithm. Selection Sort is a simple, in-place comparison sorting algorithm that divides the array into a sorted and an unsorted region, repeatedly selecting the smallest element from the unsorted region and placing it at the beginning.

## ✨ Key Features
* Reads the number of elements and array values from the user
* Sorts the array in ascending order using Selection Sort
* Prints the sorted array

## 🏗️ Data Structures Used
* **Variable-length array**: `int arr[n]` stores the input elements, sized at runtime.

## 🔧 Implementation Details

### Algorithm Explanation
1. Read `n` and populate `arr` with `n` integers.
2. In `selectionSort()`, use two nested loops:
   - Outer loop: iterate index `i` from `0` to `n-1`.
   - Inner loop: iterate index `j` from `i+1` to `n-1`.
   - If `arr[i] > arr[j]`, swap the two elements (placing the smaller element earlier).
3. After sorting, print the elements separated by spaces.

### Functions Documentation
- **`selectionSort(int arr[], int n)`**
  - **Purpose**: Sorts the array in ascending order using selection sort logic.
  - **Parameters**: `arr` — integer array; `n` — number of elements.
  - **Returns**: `void`.
  - **Logic**: Nested loops compare and swap elements to build the sorted sequence from left to right.

- **`main()`**
  - **Purpose**: Entry point; reads input, calls `selectionSort`, and prints the result.
  - **Parameters**: None.
  - **Returns**: `int` (0 on success).

## 📊 Complexity Analysis
- **Time Complexity**: O(n²) — two nested loops each running up to `n` times.
- **Space Complexity**: O(1) — in-place sorting with no additional data structures.
