# 1.7.4. Sort the products depending upon quantity by using divide and conquer techniques

## 📋 Overview
This C program reads product quantities into an array and sorts them in ascending order using a modified Bubble Sort. It prints the original quantities before sorting and the sorted quantities after sorting.

## 🎯 Purpose
The purpose of this program is to demonstrate sorting a real-world dataset (product quantities) using the Bubble Sort technique, presented in the context of a divide-and-conquer exercise. It reinforces array manipulation, sorting logic, and formatted output.

## ✨ Key Features
* Validates that the number of products is positive
* Reads and displays the original array of product quantities
* Sorts the quantities in ascending order using Bubble Sort
* Displays the sorted quantities

## 🏗️ Data Structures Used
* **Variable-length array**: `int quantities[n]` stores the product quantities at runtime.

## 🔧 Implementation Details

### Algorithm Explanation
1. Read `n` (number of products); validate it is positive.
2. Read `n` integer quantities into the `quantities` array.
3. Print the original quantities.
4. Call `bubbleSortWithSmallest()` to sort in ascending order.
5. Print the sorted quantities.

### Functions Documentation
- **`bubbleSortWithSmallest(int arr[], int n)`**
  - **Purpose**: Sorts the integer array in ascending order using Bubble Sort.
  - **Parameters**: `arr` — array of quantities; `n` — number of elements.
  - **Returns**: `void`.
  - **Logic**: Two nested loops; if `arr[j] > arr[j+1]`, swap the two elements, bubbling the largest value to the end on each pass.

- **`main()`**
  - **Purpose**: Entry point; reads input, prints original and sorted arrays.
  - **Parameters**: None.
  - **Returns**: `int` (0 on success, 1 on invalid input).

## 💻 Compilation & Usage

### Compilation
```bash
gcc "1.7.4. Sort the products depending upon quantity by using divide and conquer techniques.c" -o sort_products
```

### Running the Program
```bash
./sort_products
```

## 📥 Input/Output

### Input
* An integer `n` — the number of products.
* `n` integers — the quantity of each product.

### Output
* The original quantities on one line.
* The sorted quantities on another line.

## 📊 Complexity Analysis
- **Time Complexity**: O(n²) — Bubble Sort with two nested loops.
- **Space Complexity**: O(1) — in-place sorting.

## 🧪 Example Run
```
5
30 10 50 20 40
Original Quantities: 30 10 50 20 40
Sorted Quantities: 10 20 30 40 50
```

## ⚠️ Edge Cases & Error Handling
* Prints `"Invalid number"` and exits with code `1` if `n ≤ 0`.
* No validation for non-integer input.

## 🚧 Limitations
* Bubble Sort is inefficient for large inputs (O(n²)).
* Uses VLAs requiring C99 or later.

## 📝 Notes
This program is for educational purposes. Although the title mentions divide-and-conquer techniques, the implementation uses Bubble Sort. A true divide-and-conquer approach would use Merge Sort or Quick Sort.
