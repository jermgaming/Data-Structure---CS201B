# 1.5.8. Understanding Quick sort

## 📋 Overview
This C program demonstrates the Quick Sort algorithm. It implements a `partition()` function that selects the last element as the pivot and rearranges elements so that all elements smaller than the pivot come before it and all greater elements come after. The `quickSort()` function then recursively sorts the sub-arrays, and a `display()` function prints the array at each stage.

## 🎯 Purpose
The purpose of this program is to provide a clear understanding of the Quick Sort algorithm, one of the most efficient and widely used sorting techniques. It highlights the divide-and-conquer strategy used by Quick Sort, where a pivot element is chosen and the array is partitioned around it.

## ✨ Key Features
* Implements the partition step using the last element as pivot
* Recursively sorts both halves of the partitioned array
* Displays the array after sorting

## 🏗️ Data Structures Used
* **Array**: A fixed-size integer array `arr[15]` is used to store elements.
* **Recursion Stack**: Implicit function call stack used by the recursive `quickSort()` function.

## 🔧 Implementation Details

### Algorithm Explanation
1. **Partition**: Choose the last element as pivot. Maintain an index `i` (initialized to `lb-1`). Iterate `j` from `lb` to `ub-1`. If `arr[j] < pivot`, increment `i` and swap `arr[i]` with `arr[j]`. After the loop, swap `arr[i+1]` with `arr[ub]` (pivot placement). Return `i+1` as the pivot index.
2. **QuickSort**: If `low < high`, call `partition()` to get pivot index `j`, then recursively call `quickSort()` on `[low, j-1]` and `[j+1, high]`.
3. **Display**: Iterate through the array and print each element.

### Functions Documentation
- **`partition(int arr[], int lb, int ub)`**
  - **Purpose**: Partitions the sub-array around a pivot.
  - **Parameters**: `arr` — the array; `lb` — lower bound; `ub` — upper bound (pivot index).
  - **Returns**: The final index of the pivot element.
  - **Logic**: Uses a two-pointer technique to place all elements smaller than the pivot to its left.

- **`quickSort(int arr[], int low, int high)`**
  - **Purpose**: Recursively sorts the array using Quick Sort.
  - **Parameters**: `arr` — the array; `low` — starting index; `high` — ending index.
  - **Returns**: `void`.
  - **Logic**: Calls `partition()` and recursively sorts both partitions.

- **`display(int arr[], int n)`**
  - **Purpose**: Prints all elements of the array.
  - **Parameters**: `arr` — the array; `n` — number of elements.
  - **Returns**: `void`.

## 📊 Complexity Analysis
- **Time Complexity**: O(n log n) on average; O(n²) in the worst case (sorted input with last-element pivot).
- **Space Complexity**: O(log n) average for the recursion stack.

## 🧪 Example Run
```

```

## ⚠️ Edge Cases & Error Handling
* Worst-case O(n²) performance occurs when the array is already sorted and the last element is chosen as pivot.
* No bounds checking for the array index.

## 🚧 Limitations
* Fixed array size of 15 elements.
* Uses the last element as pivot, which can lead to poor performance on sorted data.
