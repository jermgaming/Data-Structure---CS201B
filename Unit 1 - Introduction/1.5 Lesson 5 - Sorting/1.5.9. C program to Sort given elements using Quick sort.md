## 🔧 Implementation Details

### Algorithm Explanation
The QuickSort algorithm works by selecting a pivot element, partitioning the array around the pivot, and recursively sorting the sub-arrays. The process can be broken down into the following steps:
1. Select a pivot element from the array.
2. Partition the array around the pivot element, such that all elements less than the pivot are on the left and all elements greater than the pivot are on the right.
3. Recursively apply the above steps to the sub-arrays on the left and right of the pivot element.
4. Repeat the process until the entire array is sorted.

- **`quickSort`**: `void quickSort(int arr[15], int low, int high)`
  - **Purpose**: Recursively sorts the array using the QuickSort algorithm.
  - **Parameters**:
    - `arr[15]`: The array of integers to be sorted.

    - `high`: The upper bound of the sub-array to be sorted.
  - **Returns**: None (void)
  - **Logic**: The function checks if the lower bound is less than the upper bound. If not, it returns. Otherwise, it calls the `partition` function to partition the array around a pivot element and recursively calls itself to sort the sub-arrays on the left and right of the pivot element.
