# 1.5.3. Understanding Bubble sort
## 📋 Overview
This C program implements the Bubble Sort algorithm to sort an array of integers in ascending order. The program prompts the user to input the number of elements and the elements themselves, then it sorts the array using Bubble Sort and displays the sorted array.

## 🎯 Purpose
The purpose of this program is to demonstrate the implementation of the Bubble Sort algorithm, which is a simple sorting algorithm that repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order. This program exists to provide a clear understanding of how the Bubble Sort algorithm works and how it can be used to sort an array of integers.

## ✨ Key Features
* Implements the Bubble Sort algorithm to sort an array of integers in ascending order
* Prompts the user to input the number of elements and the elements themselves
* Displays the unsorted and sorted arrays
* Uses a simple and efficient algorithm for small datasets

## 🏗️ Data Structures Used
The program uses the following data structures:
* **Arrays**: A one-dimensional array `a` of size 20 is used to store the integers input by the user. The array is defined as `int a[20]`, which means it can store up to 20 integer values.
* **Variables**: Integer variables `i`, `n`, `j`, and `temp` are used to store temporary values and loop counters. These variables are used to keep track of the current position in the array, the number of elements, and temporary values during the sorting process.

## 🔧 Implementation Details

### Algorithm Explanation
The Bubble Sort algorithm works as follows:
1. The program prompts the user to input the number of elements `n` in the array.
2. The program then prompts the user to input each element of the array, storing them in the array `a`.
3. The program prints the unsorted array to the console.
4. The program then enters a nested loop structure to perform the Bubble Sort:
   * The outer loop iterates `n` times, where `n` is the number of elements in the array.
   * The inner loop iterates from the first element to the `n-i-1` element, where `i` is the current iteration of the outer loop.
   * Inside the inner loop, the program compares each pair of adjacent elements. If the current element is greater than the next element, the program swaps them.
5. After the Bubble Sort is complete, the program prints the sorted array to the console.

## 📊 Complexity Analysis
- **Time Complexity**: The time complexity of the Bubble Sort algorithm is O(n^2) in the worst and average cases, where n is the number of elements in the array. This is because the algorithm uses two nested loops to compare and swap elements.
- **Space Complexity**: The space complexity of the Bubble Sort algorithm is O(1), which means the space required does not change with the size of the input array. This is because the algorithm only uses a constant amount of additional space to store temporary values.
