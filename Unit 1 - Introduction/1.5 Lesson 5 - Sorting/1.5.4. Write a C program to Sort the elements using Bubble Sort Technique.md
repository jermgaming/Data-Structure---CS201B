# 1.5.4. Write a C program to Sort the elements using Bubble Sort Technique

## 📋 Overview
This C program is designed to sort an array of integers in ascending order using the Bubble Sort technique. The program takes the number of elements and the elements themselves as input from the user, sorts the array, and then displays the sorted array.

## 🎯 Purpose
The purpose of this program is to demonstrate the implementation of the Bubble Sort algorithm, a simple sorting technique that works by repeatedly iterating through the array, comparing adjacent elements, and swapping them if they are in the wrong order. This program exists to provide a practical example of how the Bubble Sort algorithm can be used to sort an array of integers.

* Takes the number of elements and the elements themselves as input from the user

## 🔧 Implementation Details

### Algorithm Explanation
The Bubble Sort algorithm works by repeatedly iterating through the array, comparing adjacent elements, and swapping them if they are in the wrong order. The algorithm consists of the following steps:
1. The program prompts the user to enter the number of elements (`n`) in the array.
2. The program uses a `for` loop to read each element of the array from the user and store it in the `a` array.
3. The program displays the unsorted array by iterating through the `a` array and printing each element.
4. The program uses two nested `for` loops to implement the Bubble Sort algorithm:
	* The outer loop iterates `n` times, where `n` is the number of elements in the array.
	* The inner loop iterates `n-i-1` times, where `i` is the current iteration of the outer loop.
	* Inside the inner loop, the program compares each pair of adjacent elements and swaps them if they are in the wrong order.
5. After the sorting is complete, the program displays the sorted array by iterating through the `a` array and printing each element.
