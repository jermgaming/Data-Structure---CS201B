# 1.5.4. Write a C program to Sort the elements using Bubble Sort Technique
## 📋 Overview
This C program sorts an array of integers in ascending order using the Bubble Sort technique. The program prompts the user to input the number of elements and the elements themselves, displays the unsorted array, sorts the array, and then displays the sorted array.

## 🎯 Purpose
The main purpose of this program is to demonstrate the implementation of the Bubble Sort algorithm in C. Bubble Sort is a simple sorting algorithm that repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order. The pass through the list is repeated until the list is sorted. This program exists to provide a clear example of how to implement Bubble Sort in C and to solve the problem of sorting an array of integers in ascending order.

## ✨ Key Features
* Sorts an array of integers in ascending order using Bubble Sort
* Prompts the user to input the number of elements and the elements themselves
* Displays the unsorted array
* Displays the sorted array
* Uses a fixed-size array to store the input elements
* Uses the Bubble Sort algorithm to sort the array

## 🏗️ Data Structures Used
The program uses a single data structure: a one-dimensional array of integers (`int a[20]`). This array is used to store the input elements and is the primary data structure for the sorting operation. The array is defined as a fixed-size array with a maximum size of 20 elements.

## 🔧 Implementation Details

### Algorithm Explanation
The Bubble Sort algorithm is implemented using two nested loops:
1. The outer loop (`i`) iterates `n` times, where `n` is the number of elements in the array.
2. The inner loop (`j`) iterates from `0` to `n-i-1`, comparing adjacent elements and swapping them if they are in the wrong order.
The algorithm repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order. The pass through the list is repeated until the list is sorted.
