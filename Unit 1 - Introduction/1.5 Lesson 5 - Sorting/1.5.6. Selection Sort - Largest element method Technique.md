# 1.5.6. Selection Sort - Largest element method Technique
## 📋 Overview
The Selection Sort program is designed to sort an array of integers in ascending order using the largest element method technique. This C program prompts the user to input the number of elements and the elements themselves, then it sorts the array using the Selection Sort algorithm and prints the sorted array.

## 🎯 Purpose
The purpose of this program is to demonstrate the implementation of the Selection Sort algorithm using the largest element method technique. The Selection Sort algorithm is a simple sorting algorithm that works by repeatedly finding the largest element from the unsorted part of the array and swapping it with the first element of the unsorted part. This program aims to provide a clear understanding of how the Selection Sort algorithm works and how it can be implemented in a C program.

* Prompts the user to input the number of elements and the elements themselves
