# 4.3.5. Implementation of double ended queue using linked list - push and pop operations

## 📋 Overview
This C program implements a **Double Ended Queue (Deque)** using a singly linked list. It supports four operations: `push()` (insert at front), `pop()` (delete from front), `inject()` (insert at rear), and `eject()` (delete from rear), plus `display()` to show all elements.

## 🎯 Purpose
The purpose of this program is to demonstrate a complete linked-list-based Double Ended Queue supporting both front and rear insertions and deletions. A Deque generalizes both stacks and queues, making it a versatile data structure applicable in sliding window algorithms, palindrome checking, and scheduling.

## ✨ Key Features
* `push()` — inserts an element at the front of the deque
* `pop()` — removes the element from the front of the deque
* `inject()` — inserts an element at the rear of the deque
* `eject()` — removes the element from the rear of the deque
* `display()` — prints all elements in the deque
* Handles overflow (memory allocation failure) and underflow (empty deque) conditions

## 🏗️ Data Structures Used
* **Singly Linked List Node** used as deque nodes:
  ```c
  struct queue {
      int data;
      struct queue *next;
  };
  typedef struct queue *DeQueue;
  ```
  Two global pointers `front` and `rear` track both ends.

## 🔧 Implementation Details

### Algorithm Explanation
**Push (insert at front)**:
1. Allocate a new node.
2. If the deque is empty, set both `front` and `rear` to the new node.
3. Otherwise, set `newnode->next = front` and update `front = newnode`.

**Pop (delete from front)**:
1. If empty, print underflow and return.
2. Print the deleted element, then advance `front`. If only one node existed, set both to `NULL`. Free the old front.

**Inject (insert at rear)**:
1. Allocate a new node.
2. If empty, set `front = temp`. Otherwise, set `rear->next = temp`.
3. Update `rear = temp`.

**Eject (delete from rear)**:
1. If empty, print underflow and return.
2. Traverse to the second-to-last node. Update `rear` to that node and set `rear->next = NULL`. Free the old rear node.

### Functions Documentation
- **`push(int ele)`**: Inserts `ele` at the front.
- **`pop()`**: Removes and prints the front element.
- **`inject(int ele)`**: Inserts `ele` at the rear.
- **`eject()`**: Removes and prints the rear element.
- **`display()`**: Prints all elements from front to rear.


## 📥 Input/Output

### Input
* This is a partial implementation (no `main()` function); it is intended to be used with a driver program.

### Output
* `"Successfully inserted at front side."` on `push()`.
* `"Deleted element X from the front side."` on `pop()`.
* `"Successfully inserted at rear side."` on `inject()`.
* `"Deleted element X from the rear side."` on `eject()`.
* `"Dequeue is overflow."` / `"Dequeue is underflow."` on errors.
* All elements on `display()`.

## 📊 Complexity Analysis
- **Time Complexity**: O(1) for `push`, `pop`, `inject`; O(n) for `eject` (traversal to second-to-last node) and `display`.
- **Space Complexity**: O(n) — proportional to number of elements.

## 🧪 Example Run
```
Successfully inserted at front side.   (push 10)
Successfully inserted at rear side.    (inject 20)
Deleted element 10 from the front side. (pop)
Deleted element 20 from the rear side.  (eject)
Double ended queue is empty.            (display)
```

## ⚠️ Edge Cases & Error Handling
* Overflow (malloc failure) is detected and reported.
* Underflow (empty deque) is detected and reported for both `pop()` and `eject()`.
* Single-node deque is correctly handled in `pop()`.

## 🚧 Limitations
* `eject()` requires O(n) traversal since only a singly linked list is used; a doubly linked list would enable O(1) rear deletion.
* No `main()` function — requires a driver to test.

## 📝 Notes
This program is for educational purposes. For O(1) operations on both ends, use a doubly linked list or a circular buffer.
