# 4.1.8. Implementation of Queues using two stacks

## 📋 Overview
This C program implements a **Queue using two Linked-List-based Stacks**. It provides the standard queue operations `enqueue()`, `dequeue()`, and `display()` by leveraging two stacks (`stack1` and `stack2`). The FIFO order is maintained by transferring elements from `stack1` to `stack2` when dequeuing.

## 🎯 Purpose
The purpose of this program is to demonstrate how a queue (FIFO) can be simulated using two stacks (LIFO). This is a classic data structures exercise that illustrates how different abstract data types can be constructed from each other, and is commonly used in interviews and coursework.

## ✨ Key Features
* Implements a queue using two singly linked list stacks
* `enqueue()` always pushes onto `stack1`
* `dequeue()` transfers elements from `stack1` to `stack2` when `stack2` is empty, then pops from `stack2`
* `display()` prints all elements currently in the queue
* Handles underflow and overflow conditions

## 🏗️ Data Structures Used
* **Linked List Stack**:
  ```c
  struct stack {
      int data;
      struct stack *next;
  };
  typedef struct stack *stk;
  ```
* **Queue struct** containing two stack pointers (`stack1` and `stack2`):
  ```c
  struct queue {
      stk stack1;
      stk stack2;
  };
  typedef struct queue* Q;
  ```

## 🔧 Implementation Details

### Algorithm Explanation
**Enqueue (`enqueue`)**:
1. Push the element onto `stack1`.

**Dequeue (`dequeue`)**:
1. If both `stack1` and `stack2` are empty, print `"Queue is underflow."` and return.
2. If `stack2` is empty, pop all elements from `stack1` and push them onto `stack2` (reverses order to give FIFO).
3. Pop from `stack2` and print the deleted value.

**Display (`display`)**:
1. If both stacks are empty, print `"Queue is empty."`.
2. Otherwise, print elements from `stack1` then `stack2`.

### Functions Documentation
- **`push(stk* stack, int x)`**: Pushes `x` onto the given linked-list stack. Prints overflow if `malloc` fails.
- **`pop(stk* stack)`**: Pops and returns the top value. Prints underflow if the stack is empty.
- **`enqueue(int ele)`**: Pushes `ele` onto `stack1` and prints `"Successfully inserted."`.
- **`dequeue()`**: Removes the front element from the queue using the two-stack technique.
- **`display()`**: Prints all queue elements.

## 📊 Complexity Analysis
- **Time Complexity**: O(1) amortized per `enqueue` and `dequeue` — each element is pushed and popped at most twice.
- **Space Complexity**: O(n) — proportional to the number of elements in the queue.

## ⚠️ Edge Cases & Error Handling
* `dequeue()` handles the case when both stacks are empty.
* `push()` handles `malloc` failure (overflow).
* The global `que` pointer must be initialized before use (not shown in this partial implementation).

## 🚧 Limitations
* The global `que` pointer is declared but not initialized (`que = malloc(sizeof(struct queue))`), which must be done in `main()`.
* `display()` prints `stack1` elements in reverse insertion order, which may not reflect true FIFO order visually.

## 📝 Notes
This program is for educational purposes. A cleaner design would initialize the queue and both stacks inside `main()` or an `init()` function.
