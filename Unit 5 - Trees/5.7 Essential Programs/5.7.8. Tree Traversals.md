# 5.7.8. Tree Traversals
## 📋 Overview
This C program performs a postorder traversal on a binary tree, visiting the left subtree, then the right subtree, and finally the root node. It prints the values of the nodes in the binary tree in postorder.

## 🎯 Purpose
The purpose of this program is to demonstrate a postorder traversal algorithm on a binary tree data structure. Postorder traversal is a fundamental concept in computer science, and this program showcases its implementation. The program exists to solve the problem of traversing a binary tree in a specific order, which is essential in various applications such as tree searches, tree traversals, and tree manipulations.

## ✨ Key Features
* Performs postorder traversal on a binary tree
* Prints the values of the nodes in the binary tree in postorder
* Uses a recursive algorithm for postorder traversal
* Handles empty trees and trees with a single node
* Supports trees with multiple nodes

## 🏗️ Data Structures Used
The binary tree is represented using a struct called `Node`, which has the following structure:
```c
struct Node {
    int data;
    struct Node* left;
    struct Node* right;
};
```
This struct represents a single node in the binary tree, with `data` being the value stored in the node and `left` and `right` being pointers to the left and right child nodes, respectively.

## 🔧 Implementation Details

### Algorithm Explanation
The postorder traversal algorithm works by:
1. Checking if the current node is null (base case).
2. Recursively traversing the left subtree.
3. Recursively traversing the right subtree.
4. Visiting the current node (i.e., printing its value).

This algorithm has a time complexity of O(n), where n is the number of nodes in the tree, since each node is visited exactly once.

### Functions Documentation
- **Function Name**: `postorderTraversal(struct Node* root)`
  - **Purpose**: Performs a postorder traversal on the binary tree rooted at `root` and prints the values of the nodes in postorder.
  - **Parameters**:
    - `root`: A pointer to the root node of the binary tree.
  - **Returns**: None (void)
  - **Logic**: The function recursively traverses the left subtree, then the right subtree, and finally visits the current node by printing its value.

## 📊 Complexity Analysis
- **Time Complexity**: O(n), where n is the number of nodes in the tree, since each node is visited exactly once.
- **Space Complexity**: O(h), where h is the height of the tree, since the maximum depth of the recursive call stack is equal to the height of the tree. In the worst case, the tree is completely unbalanced (e.g., a linked list), and the space complexity is O(n).
