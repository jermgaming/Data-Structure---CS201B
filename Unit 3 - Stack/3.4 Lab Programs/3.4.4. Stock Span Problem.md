# 3.4.4. Stock Span Problem

## 📋 Overview
This C program solves the **Stock Span Problem**: given an array of stock prices for consecutive days, for each day `i`, the span is defined as the number of consecutive days (ending on day `i`) for which the stock price is less than or equal to `price[i]`. It uses a stack to compute the spans efficiently in O(n) time.

## 🎯 Purpose
The purpose of this program is to demonstrate a practical application of stacks — computing the stock span for each day. A naive approach requires O(n²) time, but the stack-based solution achieves O(n) by storing indices of days whose prices have not yet found a greater price to the right.

## ✨ Key Features
* Reads an array of daily stock prices
* Computes the span for each day using a stack of indices
* Prints the span for each day
* Implements complete stack operations: `push()`, `pop()`, `peek()`, `isEmpty()`, `display()`, and `Top()`

## 🏗️ Data Structures Used
* **Array-based Stack**: A global integer array `arr[STACK_MAX_SIZE]` (size 100000) with a `top` index to store day indices.

## 🔧 Implementation Details

### Algorithm Explanation
1. Read `n` stock prices into `input[]`.
2. For each day `i`:
   - Pop indices from the stack while the stack is non-empty and `input[stack_top] <= input[i]`.
   - If the stack is empty, `ans[i] = i + 1` (all previous days have smaller/equal prices).
   - Otherwise, `ans[i] = i - Top()` (span from the last day with a higher price).
   - Push `i` onto the stack.
3. Print all span values.

### Functions Documentation
- **`push(int element)`**: Pushes `element` onto the stack. Prints overflow message if full.
- **`pop()`**: Removes the top element silently (no underflow message printed).
- **`peek()`**: Prints the top element's value with a label.
- **`Top()`**: Returns the top element value, or `-1` if empty.
- **`isEmpty()`**: Returns `1` if the stack is empty, `0` otherwise.
- **`display()`**: Prints all stack elements from top to bottom.
- **`main()`**: Reads input, computes spans using the stack algorithm, and prints results.

## 📥 Input/Output

### Input
* An integer `n` — number of days.
* `n` integers — the stock price for each day.

### Output
* `n` integers — the span for each day, space-separated.

## 📊 Complexity Analysis
- **Time Complexity**: O(n) — each index is pushed and popped at most once.
- **Space Complexity**: O(n) — for the stack and the `ans` array.

## 🧪 Example Run
```
7
100 80 60 70 60 75 85
1 1 1 2 1 4 6
```

## ⚠️ Edge Cases & Error Handling
* Stack overflow check in `push()` (with message).
* `Top()` returns `-1` for an empty stack, which is used correctly in `ans[i] = i - Top()` when the stack is non-empty.

## 🚧 Limitations
* Uses VLAs (`int input[n]`, `int ans[n]`), which require C99 or later.
* Fixed maximum stack size of 100000.

## 📝 Notes
This program is for educational purposes and demonstrates an important real-world application of stacks. The stock span problem is a common interview question and a building block for more complex problems like the largest rectangle in a histogram.
