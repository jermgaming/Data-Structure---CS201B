# 3.5.4. Finding Next Greater Element
## 📋 Overview
The program finds the next greater element for each element in a given array. The next greater element is the first element to the right of the current element that is greater than the current element. If no such element exists, the program outputs -1.

## 🎯 Purpose
The purpose of this program is to solve the problem of finding the next greater element for each element in an array. This problem is commonly encountered in various fields such as data analysis, algorithm design, and software development. The program takes an array of integers as input, and for each element, it finds the next greater element to its right. If no greater element is found, it outputs -1.

## ✨ Key Features
* Finds the next greater element for each element in the array
* Handles cases where no greater element is found
* Uses dynamic memory allocation to store the input array and the next greater elements array
* Prints the next greater elements for each element in the array

* **Dynamic Memory Allocation**: The program uses dynamic memory allocation through the `malloc` function to allocate memory for the `arr` and `arrNext` arrays.
