# 3.3.6. Calculating Factorial of a Number Using a Stack

## 📋 Overview
This C program calculates the factorial of a given positive integer using recursion. It implements a basic array-based stack with `push()` and `pop()` operations, though the factorial calculation itself is performed recursively rather than iteratively using the stack.

## 🎯 Purpose
The purpose of this program is to demonstrate the concept of stack implementation alongside recursive factorial computation. It shows how the call stack works implicitly during recursion — each recursive call pushes a new stack frame and each return pops it.

## ✨ Key Features
* Array-based stack implementation with `push()` and `pop()` functions
* Recursive factorial calculation
* Input validation for negative numbers
* Overflow and underflow handling for the stack

## 🏗️ Data Structures Used
* **Array-based Stack**: A global `long int` array `arr[STACK_MAX_SIZE]` (size 30) with a `top` index tracking the stack's top element.

## 🔧 Implementation Details

### Algorithm Explanation
1. The program initializes a stack with `top = -1` and defines `push()` and `pop()` operations.
2. The `push()` function checks for overflow before adding an element; `pop()` checks for underflow before removing an element.
3. The `factorial()` function computes the factorial recursively:
   - Base case: if `n == 0`, return `1`.
   - Recursive case: return `n * factorial(n - 1)`.
4. The `main()` function reads an integer input, validates it is non-negative, and prints the factorial result.

### Functions Documentation
- **`push(long int element)`**: Inserts an element at the top of the stack. Prints an overflow message if the stack is full.
- **`pop()`**: Removes and returns the top element. Returns `-1` and prints an underflow message if the stack is empty.
- **`factorial(long int n)`**: Recursively computes and returns `n!`. Returns `1` for `n = 0`.
- **`main()`**: Reads user input, validates it, calls `factorial()`, and prints the result.

## 📥 Input/Output

### Input
The program expects a single non-negative integer `n` from standard input.

### Output
The program prints the factorial of `n`. If `n` is negative, it prints an error message.

## 📊 Complexity Analysis
- **Time Complexity**: O(n) — the recursive function makes `n` recursive calls.
- **Space Complexity**: O(n) — each recursive call uses stack space proportional to `n`.

## 🧪 Example Run
```

Factorial of 5 is : 120
```

## ⚠️ Edge Cases & Error Handling
* **Negative Input**: The program checks for negative input and prints an error message.
* **Stack Overflow**: The `push()` function checks if the stack is full before insertion.
* **Stack Underflow**: The `pop()` function checks if the stack is empty before removal.

## 🚧 Limitations
* The stack (`push()`/`pop()`) is implemented but not actually used for the factorial computation — the factorial is computed purely via recursion.
* The `conio.h` header is included but unused, which may cause portability issues on non-Windows systems.
* Stack size is fixed at 30, which limits the maximum number of elements that can be stored.

## 📝 Notes
The stack operations defined in this program are available for use but the factorial is computed recursively. A more instructive version would compute factorial iteratively by pushing numbers onto the stack and popping them during multiplication, demonstrating explicit stack usage.
