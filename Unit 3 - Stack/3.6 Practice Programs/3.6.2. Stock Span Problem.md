# 3.6.2. Stock Span Problem

## 📋 Overview
This C++ program solves the stock span problem — for each day's stock price, it calculates the number of consecutive previous days (including the current day) where the price was less than or equal to the current day's price.

## 🎯 Purpose
The stock span problem is a classic application of the stack data structure used in financial analysis. It helps determine how many consecutive days a stock's price has not exceeded the current day's price, which is useful for trend analysis.

## ✨ Key Features
* Calculates stock span for each element in the array
* Uses brute-force approach with nested loops
* Handles arbitrary input sizes using `std::vector`

## 🏗️ Data Structures Used
* **Vector (`std::vector<int>`)**: Stores the input stock prices and the computed span values.

## 🔧 Implementation Details

### Algorithm Explanation
1. Read the number of days `n` and the stock prices into a `vector<int> arr`.
2. For each element at index `i`:
   - Initialize a `count` to 0.
   - Iterate backwards from `i` down to 0.
   - Increment `count` for each previous price that is less than or equal to `arr[i]`.
   - Stop (break) when a price greater than `arr[i]` is encountered.
   - Print the count (span) for that day.
3. The result is output directly rather than stored in a separate array.

### Functions Documentation
- **`main()`**: Entry point. Reads input, computes the span for each price using a nested loop, and prints results.

## 📥 Input/Output

### Input
The program expects an integer `n` (number of days) followed by `n` integers representing stock prices.

### Output
The program prints `n` integers representing the stock span for each day, separated by spaces.

## 📊 Complexity Analysis
- **Time Complexity**: O(n²) — the nested loop checks all previous elements for each day.
- **Space Complexity**: O(n) — uses a vector to store the `n` prices.

## 🧪 Example Run
```
Input: 6 100 80 60 70 60 75 85
Output: 1 1 1 2 1 4 6
```

## ⚠️ Edge Cases & Error Handling
* **Empty Input**: If `n = 0`, the program outputs nothing (empty loop).
* **Single Element**: For a single-element array, the span is always `1`.
* **Strictly Increasing Prices**: Each day will have an increasing span count.

## 🚧 Limitations
* The O(n²) brute-force approach is inefficient for large inputs. An optimized O(n) solution using a stack is preferred.
* No input validation is performed for non-integer or negative values.
* The code includes commented-out lines for storing results in `ans` vector, indicating an alternative approach was considered but not used.
* Uses `<bits/stdc++.h>` header which is GCC-specific and non-standard.

## 📝 Notes
The stock span problem has an optimal O(n) solution using a monotonic stack, which tracks indices of prices in decreasing order. This brute-force version is provided for educational comparison. The commented `ans` vector suggests the code was adapted from a version that stored results before printing.
