# 3.6.3. Previous Greater Element

## 📋 Overview
This C++ program finds the previous greater element (PGE) for each element in a given array. The previous greater element is the nearest element to the left of the current element that is greater than the current element. If no such element exists, the program outputs `-1`.

## 🎯 Purpose
The previous greater element problem is a fundamental stack-based algorithm. It teaches the use of a monotonic stack — a stack that maintains elements in a specific order (in this case, decreasing from bottom to top) to efficiently find the nearest greater element to the left.

## ✨ Key Features
* Efficient O(n) solution using a monotonic stack
* Uses STL `std::stack` and `std::vector` for implementation
* Handles empty array cases gracefully

## 🏗️ Data Structures Used
* **Stack (`std::stack<int>`)**: A monotonic decreasing stack that holds candidate greater elements.
* **Vector (`std::vector<int>`)**: Used for the input array (`v`) and the result array (`ans`).

## 🔧 Implementation Details

### Algorithm Explanation
1. Read `n` and the `n` integers into `vector<int> v`.
2. Initialize an empty `stack<int> st` and an empty `vector<int> ans` for results.
3. For each element `x` in `v`:
   - While the stack is not empty and `x >= st.top()`, pop from the stack (remove elements that are too small to be a "greater" element for future items).
   - If the stack becomes empty, push `-1` to `ans` (no greater element to the left).
   - Otherwise, push `st.top()` to `ans` (the top of the stack is the previous greater element).
   - Push `x` onto the stack.
4. Print all values in `ans`.

### Functions Documentation
- **`main()`**: Entry point. Reads input, processes each element using a monotonic stack approach, stores results in `ans`, and prints them.

## 💻 Compilation & Usage

### Compilation
```bash
g++ "3.6.3. Previous Greater Element.cpp" -o "3.6.3. Previous Greater Element"
```

### Running the Program
```bash
./3.6.3. Previous Greater Element
```

## 📥 Input/Output

### Input
The program expects an integer `n` (size of array) followed by `n` integers representing the input array.

### Output
The program prints `n` integers representing the previous greater element for each position, separated by spaces. Outputs `-1` where no greater element exists to the left.

## 📊 Complexity Analysis
- **Time Complexity**: O(n) — each element is pushed and popped from the stack at most once.
- **Space Complexity**: O(n) — the stack and result vector each use O(n) space.

## 🧪 Example Run
```
Input: 5 4 10 5 8 3
Output: -1 -1 10 10 8
```

## ⚠️ Edge Cases & Error Handling
* **Empty Input**: If `n = 0`, the program outputs nothing.
* **First Element**: The first element always has no previous greater element, so `-1` is output.
* **All Equal Elements**: Each element after the first will find the same value as the previous greater element.
* **Strictly Increasing Array**: Each element's previous greater element is the preceding element.
* **Strictly Decreasing Array**: All elements except the first will have `-1` as the previous greater element.

## 🚧 Limitations
* Uses `<bits/stdc++.h>` header which is GCC-specific and non-standard.
* No input validation for invalid or negative array sizes.
* The program initializes `v` with `-1` values of size `n` but overwrites them immediately — this is redundant.

## 📝 Notes
This problem is the complement of the Next Greater Element (NGE) problem. The monotonic stack approach used here is elegant and efficient, processing the entire array in a single pass. The key insight is maintaining a stack of decreasing values so that for each element, the top of the stack is always the nearest greater element to its left.
