# 3.2.2. Implementation of Stack using Arrays - push() and display() operations

## 📋 Overview
This C program implements two fundamental stack operations using an array: `push()` to add an element onto the top of the stack, and `display()` to print all current stack elements from top to bottom. The stack uses a fixed-size array of 10 elements and a `top` variable to track the stack's topmost position.

## 🎯 Purpose
The purpose of this program is to introduce array-based stack implementation by focusing on the two most fundamental operations — pushing an element and displaying the stack's contents. It demonstrates how the LIFO (Last In, First Out) principle is enforced through the `top` index and overflow detection.

## ✨ Key Features
* Implements `push()` with stack overflow detection
* Implements `display()` that prints elements from top to bottom
* Uses a global fixed-size array and a `top` index variable
* Prints `"Stack is overflow"` when attempting to push onto a full stack
* Prints `"Stack is empty."` when attempting to display an empty stack

## 🏗️ Data Structures Used
* **Array-based Stack**: A global integer array `arr[STACK_MAX_SIZE]` (size 10) with a global `top` variable initialized to `-1` to represent an empty stack.

## 🔧 Implementation Details

### Algorithm Explanation
**Push (`push`)**:
1. If `top == STACK_MAX_SIZE - 1`, print `"Stack is overflow"` and return.
2. Otherwise, increment `top` and store `element` at `arr[top]`.
3. Print `"Successfully pushed."`.

**Display (`display`)**:
1. Copy `top` into a temporary variable `temp`.
2. If `temp == -1`, print `"Stack is empty."` and return.
3. Otherwise, print `"Elements of the stack are : "`, then loop from `temp` down to `0`, printing each element.

### Functions Documentation
- **`push(int element)`**
  - **Purpose**: Pushes `element` onto the top of the stack.
  - **Parameters**: `element` — integer value to push.
  - **Returns**: `void`.

- **`display()`**
  - **Purpose**: Prints all stack elements from top to bottom.
  - **Parameters**: None.
  - **Returns**: `void`.


## 📥 Input/Output

### Input
* This is a partial implementation (no `main()` function); it is intended to be used with a driver program.

### Output
* `"Successfully pushed."` after each successful push.
* `"Stack is overflow"` when the stack is full.
* `"Stack is empty."` when displaying an empty stack.
* Stack elements from top to bottom when displaying a non-empty stack.

## 📊 Complexity Analysis
- **Time Complexity**: O(1) for `push`; O(n) for `display` (where n is the number of elements).
- **Space Complexity**: O(1) — fixed-size array allocated at compile time.

## ⚠️ Edge Cases & Error Handling
* Overflow is handled: pushing to a full stack prints a message and returns without modifying the stack.
* Empty stack display is handled: prints an appropriate message instead of printing nothing.

## 🚧 Limitations
* Fixed stack size of 10 (`STACK_MAX_SIZE`); cannot grow dynamically.
* No `pop()`, `peek()`, or `isEmpty()` functions in this file (covered in subsequent lessons).
* Global state makes the implementation unsuitable for multi-stack or multi-threaded use.

## 📝 Notes
This program is for educational purposes. A production-quality stack would use dynamic memory allocation and encapsulate state within a struct.
