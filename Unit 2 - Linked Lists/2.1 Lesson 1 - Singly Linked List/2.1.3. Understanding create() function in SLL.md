# 2.1.3. Understanding create() function in SLL
## 📋 Overview
This C program implements a Singly Linked List (SLL) data structure and provides a `createNode()` function to dynamically allocate memory for new nodes. The program demonstrates the basic concept of creating a new node in a SLL and initializing its `next` pointer to `NULL`.

## 🎯 Purpose
The purpose of this program is to create a new node in a SLL data structure. The `createNode()` function dynamically allocates memory for a new node and initializes its `next` pointer to `NULL`. This function is a fundamental building block for constructing and manipulating SLLs.

## ✨ Key Features
* Dynamically allocates memory for new nodes using `malloc()`
* Initializes the `next` pointer of new nodes to `NULL`
* Returns a pointer to the newly created node
* Implements a basic SLL data structure using a `struct node` with `data` and `next` members

## 🏗️ Data Structures Used
The program uses a Singly Linked List (SLL) data structure, which is a linear data structure where each node contains a value and a reference (i.e., a "link") to the next node in the sequence. The SLL is implemented using a `struct node` with two members:
* `data`: an integer that stores the value of the node
* `next`: a pointer to the next node in the sequence

The `struct node` is defined as follows:
```c
struct node {
    int data;
    struct node *next;
};
```
A typedef is used to define a pointer to the `struct node` as `NODE`:
```c
typedef struct node *NODE;
```
This allows for more concise and readable code when working with nodes in the SLL.

This algorithm has a time complexity of O(1) since it only involves a constant number of operations.
