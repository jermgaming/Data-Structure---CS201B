# 2.1.5. Program to Insert an element at Begin and Count number of Nodes in Singly Linked List
## 📋 Overview
This C program implements a Singly Linked List data structure, providing functions to insert an element at the beginning of the list and count the number of nodes in the list. The program also includes a function to traverse and print the elements of the linked list.

## 🏗️ Data Structures Used
The program implements and uses a Singly Linked List data structure, which is a linear data structure where each element (node) points to the next element in the sequence. Each node in the list contains an integer data field and a pointer to the next node in the list. The linked list is defined using a struct node with two members: `data` and `next`.

## 🔧 Implementation Details

### Algorithm Explanation
The program uses the following algorithms:
*   **Insertion Algorithm**: The `insertAtBegin` function uses a simple insertion algorithm to add a new node at the beginning of the linked list. It creates a new node, sets its data field to the given value, and updates the `next` pointer of the new node to point to the current first node. If the list is empty, the new node becomes the first node.
*   **Traversal Algorithm**: The `traverseList` function uses a simple traversal algorithm to iterate through the linked list and print the elements. It starts at the first node and follows the `next` pointers until it reaches the end of the list (i.e., a node with a `NULL` `next` pointer).
*   **Counting Algorithm**: The `count` function uses a simple counting algorithm to count the number of nodes in the linked list. It starts at the first node and increments a counter for each node it encounters, following the `next` pointers until it reaches the end of the list.

    *   **Returns**: A pointer to the updated first node in the linked list (`NODE` type)

    *   **Purpose**: Counts the number of nodes in the linked list.
    *   **Parameters**:
        *   `first`: A pointer to the first node in the linked list (`NODE` type)
