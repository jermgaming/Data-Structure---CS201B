# 2.1.4. Write a C program to Create a Singly Linked List
## 📋 Overview
This C program creates a singly linked list and provides functions to add nodes to the list and traverse the list to display its contents. The program utilizes dynamic memory allocation to store nodes in the linked list.

## 🎯 Purpose
The purpose of this program is to demonstrate the implementation of a singly linked list data structure in C. A singly linked list is a linear data structure where each node contains a value and a reference to the next node in the sequence, allowing for efficient insertion and deletion of nodes. This program solves the problem of creating and manipulating a dynamic list of integers.

## ✨ Key Features
* Creates a singly linked list using dynamic memory allocation
* Provides functions to add nodes to the end of the linked list
* Includes a function to traverse the linked list and print the values of all nodes
* Demonstrates basic operations on a linked list, such as node creation and traversal

## 🏗️ Data Structures Used
The data structure used in this program is a singly linked list. A singly linked list is defined as a sequence of nodes, where each node contains an integer value (`data`) and a pointer to the next node in the list (`next`). The `node` struct is defined as follows:
```c
struct node {
    int data;
    struct node *next;
};
```
The `NODE` type is a pointer to a `node` struct, which represents a node in the linked list.
