# 📋 Overview
The provided C program implements a Singly Linked List (SLL) data structure and offers various operations to manipulate and analyze the list. The main purpose of this program is to demonstrate the creation, sorting, and intersection of Singly Linked Lists.

## 🏗️ Data Structures Used
The primary data structure used in this program is a Singly Linked List (SLL). A SLL is a linear data structure where each element is a separate object, and each element (or "node") points to the next node in the sequence. This structure allows for efficient insertion and deletion of nodes at any position in the list.
