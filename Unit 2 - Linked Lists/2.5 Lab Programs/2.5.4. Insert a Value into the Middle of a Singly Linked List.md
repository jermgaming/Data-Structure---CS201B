# 2.5.4. Insert a Value into the Middle of a Singly Linked List
## 📋 Overview
This C program is designed to insert a new value into the middle of a singly linked list. It achieves this by first creating a linked list based on user input, identifying the middle node using the slow and fast pointer technique, and then inserting a new node with a user-provided value at the middle position of the list.

## 🎯 Purpose
The purpose of this program is to demonstrate the implementation of a singly linked list and the insertion of a new node at a specific position, in this case, the middle. It solves the problem of dynamically modifying a linked list by adding new elements at desired positions, which is a fundamental operation in data structures and algorithms.

## ✨ Key Features
* Creates a singly linked list based on user input
* Identifies the middle node of the linked list using the slow and fast pointer technique
* Inserts a new node with a user-provided value at the middle position of the list
* Prints the linked list before and after the insertion

## 🏗️ Data Structures Used
A singly linked list is a linear data structure where each node contains a value and a reference (i.e., a "link") to the next node in the sequence. This structure allows for efficient insertion and deletion of nodes at any position in the list. In this program, the singly linked list is defined by a struct `node` that has two members: `data` to store the value of the node and `next` to point to the next node in the list.

## 🔧 Implementation Details

### Algorithm Explanation
The program uses the slow and fast pointer technique to find the middle node of the linked list. This technique involves moving two pointers, `slow` and `fast`, through the list at different speeds. The `fast` pointer moves twice as fast as the `slow` pointer, so when the `fast` pointer reaches the end of the list, the `slow` pointer will be at the middle node. Once the middle node is identified, a new node with the user-provided value is created and inserted at the middle position by updating the `next` pointer of the middle node to point to the new node.

  - **Purpose**: Inserts a new node with the given value `x` at the end of the linked list.

  - **Logic**: Traverses the list from the head node and prints the `data` member of each node until it reaches the end of the list.

  - **Purpose**: The entry point of the program, responsible for reading user input, creating the linked list, inserting a new node at the middle position, and printing the updated list.
  - **Parameters**: None (standard `main` function).

  - **Logic**: Reads the number of nodes to create, creates the linked list by reading values and inserting them at the end, finds the middle node, reads the value to insert, inserts the new node at the middle position, and prints the list before and after the insertion.
