# 2.5.2. Cycle Detection in Linked List
## 📋 Overview
This C program is designed to detect whether a singly linked list has a cycle or not. The program takes the number of nodes, the data for each node, and a position value as input from the user. It then prints whether the list has a cycle or not based on the position value.

## 🎯 Purpose
The primary purpose of this program is to demonstrate the concept of cycle detection in a linked list. A cycle in a linked list occurs when a node's next pointer points to a node that is already present in the list, creating a loop. This program aims to identify such cycles and inform the user about their presence.

## ✨ Key Features
*   Takes user input for the number of nodes, node data, and a position value.
*   Prints whether the list has a cycle or not based on the position value.
*   Implements a singly linked list using a `struct node` with `data` and `next` members.
*   Provides a basic framework for cycle detection in linked lists.

## 🏗️ Data Structures Used
The program utilizes a singly linked list, which is a linear data structure where each node has a reference (i.e., a "link") to the next node in the sequence. Each node is defined using a `struct node` with two members:
*   `data`: an integer that stores the value of the node.
*   `next`: a pointer to the next node in the list.

## 🔧 Implementation Details

### Algorithm Explanation
The original code does not implement a specific algorithm for cycle detection. However, a common approach is to use Floyd's cycle-finding algorithm, also known as the "tortoise and the hare" algorithm. This algorithm works by advancing two pointers through the list at different speeds:
*   The "tortoise" moves one step at a time.
*   The "hare" moves two steps at a time.
If there is a cycle, these two pointers will eventually meet. If there is no cycle, the "hare" will reach the end of the list.
