## 📋 Overview

## 🎯 Purpose
The purpose of this program is to implement and demonstrate the functionality of a Circularly Linked List (CLL) data structure. A CLL is a type of linked list where the last node points back to the first node, forming a circular structure. This program solves the problem of creating and managing a CLL, allowing users to add nodes and traverse the list to display its elements.

* Implements a Circularly Linked List (CLL) data structure

## 🏗️ Data Structures Used
The program uses a Circularly Linked List (CLL) data structure, which is composed of nodes. Each node contains an integer data field and a pointer to the next node in the list. The CLL is defined as follows:
```c
struct node {
    int data;
    struct node *next;
};
typedef struct node *NODE;
```
The CLL is a dynamic data structure, meaning that nodes can be added or removed at runtime. The program uses pointers to manage the nodes and traverse the list.
