# 2.2.2. Write a Program to Create a Double Linked List 01

## 📋 Overview
This C program demonstrates the creation of a single node for a Doubly Linked List (DLL). It defines the node structure with `data`, `prev`, and `next` pointers, and provides a `createNodeInDLL()` function that allocates and initializes a new node with both pointers set to `NULL`.

## 🎯 Purpose
The purpose of this program is to introduce the fundamental building block of a Doubly Linked List — the node. By understanding how to create and initialize a DLL node, learners can build upon this foundation to implement more complex DLL operations such as insertion, deletion, and traversal.

## ✨ Key Features
* Defines the doubly linked list node structure with `prev` and `next` pointers
* Implements a `createNodeInDLL()` function that allocates memory and initializes a new node
* Sets both `prev` and `next` pointers to `NULL` upon creation

## 🏗️ Data Structures Used
* **Doubly Linked List Node**:
  ```c
  struct node {
      int data;
      struct node *prev;
      struct node *next;
  };
  typedef struct node * NODE;
  ```
  Each node stores an integer `data` value and two pointers to neighboring nodes.

## 🔧 Implementation Details

### Algorithm Explanation
1. Allocate memory for a new node using `malloc`.
2. Set `head->prev = NULL` — no predecessor initially.
3. Set `head->next = NULL` — no successor initially.
4. Return the newly created node.

### Functions Documentation
- **`createNodeInDLL()`**
  - **Purpose**: Allocates and initializes a new doubly linked list node.
  - **Parameters**: None.
  - **Returns**: `NODE` — pointer to the newly created node.
  - **Logic**: Allocates memory using `malloc`, initializes both pointers to `NULL`, and returns the node pointer.

## 📥 Input/Output

### Input

### Output
* No direct output; returns a pointer to the newly created node.

## 📊 Complexity Analysis
- **Time Complexity**: O(1) — constant time for memory allocation and initialization.
- **Space Complexity**: O(1) — allocates memory for a single node.

## 🧪 Example Run
```c
NODE head = createNodeInDLL();
head->data = 10;
// head->prev == NULL, head->next == NULL
```

## ⚠️ Edge Cases & Error Handling
* No check for `malloc` failure; if memory allocation fails, the returned pointer will be `NULL`, and using it without checking will cause a segmentation fault.

## 🚧 Limitations
* This is a partial implementation; a complete DLL program requires insertion, deletion, and traversal functions.
* No error handling for `malloc` failure.

## 📝 Notes
This program is for educational purposes and is designed as an introductory step to building a full Doubly Linked List. It should be extended with `insertAtEnd()`, `insertAtBegin()`, `delete()`, and `traverse()` functions.
