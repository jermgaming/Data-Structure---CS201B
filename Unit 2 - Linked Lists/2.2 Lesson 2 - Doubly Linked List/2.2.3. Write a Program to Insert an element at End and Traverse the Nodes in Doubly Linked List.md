# 2.2.3. Write a Program to Insert an element at End and Traverse the Nodes in Doubly Linked List

## 📋 Overview
This C program implements two key operations on a Doubly Linked List (DLL): inserting a new node at the end of the list, and traversing the entire list to display all node values. It also includes the `createNodeInDLL()` helper function for node creation.

## 🎯 Purpose
The purpose of this program is to demonstrate end insertion and forward traversal in a Doubly Linked List. These are foundational operations that enable construction and inspection of a DLL, building on the basic node-creation concept introduced in earlier lessons.

## ✨ Key Features
* Creates a new DLL node with both `prev` and `next` set to `NULL`
* Inserts an element at the end of the list, handling the empty-list case
* Traverses and prints all nodes from head to tail in the format `data <--> NULL`

## 🏗️ Data Structures Used
* **Doubly Linked List Node**:
  ```c
  struct node {
      int data;
      struct node *prev;
      struct node *next;
  };
  typedef struct node * NODE;
  ```

## 🔧 Implementation Details

### Algorithm Explanation
**Insert at End (`insertAtEndInDLL`)**:
1. If the list is empty (`!first`), create a new node, assign `x` to its `data`, and return it as the new head.
2. Otherwise, traverse to the last node using a `temp` pointer.
3. Create a new node, assign `x` to its `data`, link it: set `temp->next = newNode` and `newNode->prev = temp`.
4. Return `first` (head remains unchanged).

**Traverse (`traverseListInDLL`)**:
1. Start from `first` and iterate while `temp != NULL`.
2. Print each node's data followed by `" <--> "`.
3. Print `"NULL"` at the end.

### Functions Documentation
- **`createNodeInDLL()`**
  - **Purpose**: Allocates and returns a new DLL node with both pointers set to `NULL`.
  - **Parameters**: None.
  - **Returns**: `NODE`.

- **`insertAtEndInDLL(NODE first, int x)`**
  - **Purpose**: Inserts a new node with value `x` at the end of the list.
  - **Parameters**: `first` — head pointer; `x` — value to insert.
  - **Returns**: `NODE` — updated head.

- **`traverseListInDLL(NODE first)`**
  - **Purpose**: Prints all node values from head to tail.
  - **Parameters**: `first` — head pointer.
  - **Returns**: `void`.

## 📊 Complexity Analysis
- **Time Complexity**: O(n) for both insertion at end (traversal to last node) and traversal.
- **Space Complexity**: O(1) per insertion (one new node allocated).

## 🧪 Example Run
```
10 <--> 20 <--> 30 <--> NULL
```

## ⚠️ Edge Cases & Error Handling
* No check for `malloc` failure in `createNodeInDLL()`.
* `insertAtEndInDLL` correctly handles the empty-list case.

## 🚧 Limitations
* End insertion requires O(n) traversal; a tail pointer would make it O(1).
* No `main()` function — requires a driver to test.

## 📝 Notes
This program is for educational purposes. A complete DLL implementation would maintain a tail pointer for O(1) end insertion and include deletion and search operations.
