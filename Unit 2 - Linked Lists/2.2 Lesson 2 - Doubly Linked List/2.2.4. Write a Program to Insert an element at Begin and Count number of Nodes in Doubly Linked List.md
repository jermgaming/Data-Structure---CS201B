# 2.2.4. Write a Program to Insert an element at Begin and Count number of Nodes in Doubly Linked List

## 📋 Overview
This C program implements three operations on a Doubly Linked List (DLL): creating a new node, inserting a new element at the beginning of the list, and counting the total number of nodes. It also includes forward traversal to display the list.

## 🎯 Purpose
The purpose of this program is to demonstrate beginning insertion and node counting in a Doubly Linked List. These operations are essential DLL skills, showing how new elements can be prepended in O(1) time and how the list length can be determined by traversal.

## ✨ Key Features
* Allocates and initializes a new DLL node
* Inserts a new element at the beginning of the list in O(1) time
* Counts the total number of nodes by traversing the list
* Traverses and displays all nodes in the format `data <--> NULL`

## 🏗️ Data Structures Used
* **Doubly Linked List Node**:
  ```c
  struct node {
      int data;
      struct node *prev;
      struct node *next;
  };
  typedef struct node * NODE;
  ```

## 🔧 Implementation Details

### Algorithm Explanation
**Count (`countInDLL`)**:
1. Initialize `count = 0` and start from `first`.
2. Traverse the list, incrementing `count` for each node.
3. Return `count`.

**Insert at Begin (`insertAtBeginInDLL`)**:
1. Create a new node `temp` with value `x`.
2. Set `temp->next = first` and `first->prev = temp`.
3. Set `first = temp` (new node becomes the head).
4. Return the new head.

**Traverse (`traverseListInDLL`)**:
1. Iterate from `first` to `NULL`, printing each node's data followed by `" <--> "`.
2. Print `"NULL"` at the end.

### Functions Documentation
- **`createNodeInDLL()`**
  - **Purpose**: Allocates a new DLL node with both pointers set to `NULL`.
  - **Returns**: `NODE`.

- **`countInDLL(NODE first)`**
  - **Purpose**: Returns the number of nodes in the list.
  - **Parameters**: `first` — head pointer.
  - **Returns**: `int` — node count.

- **`insertAtBeginInDLL(NODE first, int x)`**
  - **Purpose**: Inserts a new node with value `x` at the beginning.
  - **Parameters**: `first` — current head; `x` — value to insert.
  - **Returns**: `NODE` — new head.

- **`traverseListInDLL(NODE first)`**
  - **Purpose**: Prints all node values from head to tail.
  - **Parameters**: `first` — head pointer.
  - **Returns**: `void`.

## 📊 Complexity Analysis
- **Time Complexity**: O(1) for `insertAtBeginInDLL`; O(n) for `countInDLL` and `traverseListInDLL`.
- **Space Complexity**: O(1) per insertion.

## 🧪 Example Run
```
30 <--> 20 <--> 10 <--> NULL

```

## ⚠️ Edge Cases & Error Handling
* No check for `malloc` failure.
* `insertAtBeginInDLL` assumes `first` is a valid non-NULL pointer; inserting into an empty list (where `first` is `NULL`) will cause `first->prev = temp` to dereference a NULL pointer.

## 🚧 Limitations
* The current `insertAtBeginInDLL` implementation has a null-pointer dereference bug when inserting into an empty list.
* No `main()` function — requires a driver to test.

## 📝 Notes
This program is for educational purposes. The null-pointer bug can be fixed by adding a null check before `first->prev = temp`.
