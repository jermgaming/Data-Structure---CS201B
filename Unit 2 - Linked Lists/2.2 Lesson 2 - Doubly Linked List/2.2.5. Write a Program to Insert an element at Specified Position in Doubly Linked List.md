# 2.2.5. Write a Program to Insert an element at Specified Position in Doubly Linked List
## 📋 Overview
This C program implements a doubly linked list (DLL) and provides a function to insert an element at a specified position in the list. The program allows users to create a DLL, insert nodes at specific positions, and traverse the list to display its contents.

## 🎯 Purpose
The purpose of this program is to demonstrate the implementation of a doubly linked list and the insertion of elements at specified positions. A doubly linked list is a type of linked list where each node has two pointers: `prev` and `next`, which point to the previous and next nodes in the list, respectively. This allows for efficient insertion and deletion of nodes at any position in the list.

## ✨ Key Features
* Implementation of a doubly linked list (DLL) data structure
* Function to create a new node in the DLL with a given data value
* Function to insert a new node at a specified position in the DLL
* Function to traverse the DLL and print the data values of all nodes
* Handling of edge cases such as inserting at the beginning or end of the list, and inserting at a position out of range

## 🏗️ Data Structures Used
The program uses a doubly linked list (DLL) data structure, which is defined as follows:
```c
struct node {
    int data;
    struct node *prev;
    struct node *next;
};
typedef struct node * NODE;
```
Each node in the DLL has three components: `data`, `prev`, and `next`. The `data` component stores the actual data value of the node, while the `prev` and `next` components store pointers to the previous and next nodes in the list, respectively.

## 🔧 Implementation Details

### Algorithm Explanation
The program uses the following algorithms:

*   **Node creation**: The `createNodeInDLL` function uses dynamic memory allocation (malloc) to create a new node with the given data value.
*   **Insertion at a specified position**: The `insertAtPositionInDLL` function uses a simple iterative approach to find the node at the specified position and insert the new node. It handles edge cases such as inserting at the beginning or end of the list.
*   **Traversal**: The `traverseListInDLL` function uses a simple iterative approach to traverse the DLL and print the data values of all nodes.

### Functions Documentation
#### `createNodeInDLL(int x)`
*   **Purpose**: Creates a new node in the DLL with the given data value `x`.
*   **Parameters**: `int x` (the data value to be stored in the new node).
*   **Returns**: A pointer to the newly created node (`NODE` type).
*   **Logic**: The function allocates memory for a new node using `malloc`, initializes the `prev` and `next` pointers to `NULL`, and stores the data value `x` in the new node.

#### `insertAtPositionInDLL(NODE first, int position, int x)`
*   **Purpose**: Inserts a new node with the given data value `x` at the specified `position` in the DLL.
*   **Parameters**:
    *   `NODE first`: A pointer to the first node in the DLL.
    *   `int position`: The position where the new node should be inserted (1-indexed).
    *   `int x`: The data value to be stored in the new node.
*   **Returns**: A pointer to the first node in the modified DLL (`NODE` type).
*   **Logic**: The function checks if the list is empty and the position is 1, and if so, returns the new node as the first node. If the position is 1, the new node is inserted at the beginning of the list. Otherwise, the function iterates through the list to find the node at the specified position and inserts the new node.

#### `traverseListInDLL(NODE first)`
*   **Purpose**: Traverses the DLL starting from the first node and prints the data values of all nodes.
*   **Parameters**: `NODE first` (a pointer to the first node in the DLL).
*   **Returns**: None (void function).
*   **Logic**: The function iterates through the list, printing the data values of all nodes, and stops when it reaches the end of the list (`NULL`).
