# 2.6.4. List deletion with Joseph
## 📋 Overview
This C program simulates a Josephus problem, a classic problem in computer science and mathematics. It creates a linked list of integers, deletes a specified number of nodes from the beginning of the list, and then prints the remaining linked list.

## 🎯 Purpose
The purpose of this program is to demonstrate the concept of linked lists and node deletion. It solves the problem of deleting a specified number of nodes from the beginning of a linked list and then printing the remaining list. This program can be used to simulate real-world scenarios, such as a Josephus problem, where a group of people are standing in a circle and every nth person is eliminated.

## ✨ Key Features
* Creates a linked list of integers
* Deletes a specified number of nodes from the beginning of the list
* Prints the remaining linked list
* Demonstrates the concept of linked lists and node deletion
* Simulates a Josephus problem

## 🏗️ Data Structures Used
The program uses a singly linked list data structure, which is a linear data structure where each element (node) points to the next element. Each node in the linked list contains an integer data field and a pointer to the next node. The linked list is defined as follows:
```c

    struct node* next;

```
The linked list is created by inserting nodes at the beginning of the list using the `insertAtBeginning` function.
