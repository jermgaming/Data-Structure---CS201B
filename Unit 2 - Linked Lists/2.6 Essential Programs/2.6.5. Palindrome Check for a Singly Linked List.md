# 2.6.5. Palindrome Check for a Singly Linked List
## 📋 Overview
This C program checks whether a singly linked list is a palindrome. A palindrome is a sequence that reads the same backward as forward. In the context of a linked list, this means that the data values in the nodes are the same when traversed from the beginning to the end as when traversed from the end to the beginning.

## 🎯 Purpose
The purpose of this program is to determine whether a given singly linked list is a palindrome. This is achieved by implementing a series of functions that work together to check for palindromicity. The program reads input values from the user, constructs a linked list, and then checks whether the list is a palindrome.

* Uses a slow and fast pointer algorithm to find the middle of the linked list
